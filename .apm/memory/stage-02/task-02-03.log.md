# Task 2.3 - Connector Runtime Contracts

## Summary
Implemented the worker-side connector runtime contracts, sample connector execution path, source configuration loader, registry, runtime helpers, Celery task/scheduler wiring, focused tests, and connector documentation updates.

## Details
Added a worker-owned `sentineldrive_worker.connectors` package with source configuration, retry policy, cursor context, connector protocol, Raw Intelligence-shaped payloads, deterministic hashing, registry, sample connector, and runtime execution helpers. The runtime skips disabled or not-yet-implemented configured sources, runs implemented connectors independently, applies timeout/retry/rate-limit behavior, records sanitized error states, advances cursors, and returns JSON-serializable source run records.

Kept the existing `sentineldrive.sync_sources` Celery task name and worker scripts stable. Celery Beat now schedules the sync task from `SOURCE_SYNC_INTERVAL_SECONDS`. Docker packaging now copies the new worker runtime package.

Updated configuration and documentation to include `SOURCE_ENABLED_SAMPLE`, the connector runtime contract, database-backed source configuration shape, Raw Intelligence output fields, sample connector status, and current skeleton boundaries.

# Task 3.2 - NVD and CISA KEV Connectors

## Summary
Implemented built-in NVD CVE and CISA KEV Connectors using the existing connector runtime and raw payload shape, with mocked tests and documentation updates.

## Details
Added source-agnostic HTTP/date helpers plus `NvdConnector` and `CisaKevConnector`. NVD uses API 2.0 modified-date windows, optional `apiKey` header support, conservative two-year first sync, capped pagination, JSON cursor state, and CVE metadata extraction. CISA KEV parses official-style JSON catalogs and CSV rows, maps KEV fields into raw payload metadata, and uses date-added cursor markers.

Registered `nvd` and `cisa-kev` through the built-in connector registry path. Updated connector, source configuration, testing, and environment docs to reflect implemented NVD/CISA behavior.

Committed changes on branch `feat/source-connectors` with commit `a107e2b` using message `feat: add source connectors`.

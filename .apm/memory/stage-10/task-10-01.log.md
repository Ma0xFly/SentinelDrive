# Task 10.1 - 访客只读后端

## Summary

新增可选用户依赖 `get_optional_current_user`，将情报列表/详情、`/stats/overview`、信源列表/详情改为匿名可读（凭据非法仍 401），并按认证状态裁剪信源运维字段。新增 6 个访客只读测试，后端测试 90 passed 无回归。

## Details

- **可选用户依赖**（`backend/app/api/deps.py`）：新增 `get_optional_current_user`——复用现有 `HTTPBearer(auto_error=False)`，`credentials is None` 时返回 `None`（匿名）；有凭据时复用 `decode_access_token` 校验逻辑，凭据非法（含非 bearer scheme）仍抛 401。`get_current_user` 原样保留，供写端点继续使用。
- **公开 read 面**（改用 `get_optional_current_user`）：`GET /intelligence`、`GET /intelligence/{id}`（`routes/intelligence.py`）；`GET /stats/overview`（`routes/stats.py`）；`GET /sources`、`GET /sources/{source_id}`（`routes/sources.py`）。情报与统计端点除 `del current_user` 外的响应逻辑不变。
- **信源运维字段裁剪**（`schemas/sources.py` + `routes/sources.py`）：把 `SourceStatusResponse` 拆为继承式——新增 `SourcePublicResponse`（仅 `id/name/source_type/status/enabled/base_url`）与 `SourcePublicPageResponse`；`SourceStatusResponse` 继承 `SourcePublicResponse` 并保留 `config/last_success_at/last_error_at/last_error_message/failure_count/sync_state/recent_jobs/created_at/updated_at`；`SourceStatusPageResponse` 继承 `SourcePublicPageResponse` 并将 `items` 收窄为 `list[SourceStatusResponse]`。认证响应的字段与值与原实现完全一致。
- **端点分认证态返回**：列表/详情用 `response_model=SourceStatusPageResponse | SourcePublicPageResponse` 与 `SourceStatusResponse | SourcePublicResponse`（Pydantic 继承让 smart-union 精确选择）。匿名时跳过 `JobLog`/`SyncState` 查询，并强制 `sort=NAME`（不暴露失败排序）。`_source_public_response` 只输出公开字段，经 `safe_url` 脱敏 base_url。
- **写端点保持强认证**：`POST /manual-entries`、`PATCH /alerts/{id}/status`、`PATCH /sources/{id}/status`、`POST /sources/pipeline/trigger`、`POST /alerts/evaluate`、导出端点、用户端点均未改动，仍走 `get_current_user`/`require_admin_user`。

## Important Findings

- **并行 agent 共享同一 git 工作目录会互相干扰分支**：本任务按 Workspace 要求从 `main` 建分支后，另一个并行 worker agent 对同一目录执行了 `git checkout`，使我在随后 `git commit` 时落到了它当前的分支上。Manager 在并行派发多个 Worker 到同一工作目录时需注意：应使用独立 worktree，或冻结/协调 checkout 时机，否则各 Worker 的提交可能串分支。（本次已通过重设分支指针修复，未见数据丢失。）
- **公开端点仍带 OpenAPI `HTTPBearer` 安全标记**：`get_optional_current_user` 依赖 `bearer_scheme`，故这些匿名可读端点在实际响应中匿名可访问，但 OpenAPI 文档仍标注需要 Bearer。这不会影响运行时行为，但前端 Task 10.2 或 API 文档需要知晓「文档显示锁、实际可匿名」这一差异；若要求文档精确，可在端点层显式声明 `security=[{}]`。
- 认证响应结构对已有客户端完全向后兼容（字段与值不变）；匿名响应是新的精简结构，前端需按 `SourcePublicResponse` 处理信源公开字段。

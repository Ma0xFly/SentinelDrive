2. **威胁情报列表**：ProTable，筛选覆盖后端全部支持参数（标题关键字、CVE、类型、严重度、风险等级、厂商、产品、标签、来源、状态、组件、攻击面、排序），风险/严重度徽章色，CSV 导出（blob 下载），行进入详情。管理员可见「手工录入」快捷入口。
3. **情报详情**（`/intelligence/:id` 独立路由）：基础信息、摘要、风险评估（风险分/等级/评分解释/评分因素键值）、来源归因表（来源名称/URL/外部编号/首末发现时间）、去重键与 external_ids、关联告警列表、导出 Markdown/PDF。
4. **告警工作台**：状态/风险等级筛选列表；抽屉详情（字段、备注、关联情报跳转）；状态流转表单（目标状态全量可选，备注未编辑时保留原备注、清空提交即清除，对齐旧版语义）；成功/失败中文反馈。
5. **数据源管理**：列表（状态/类型/关键字筛选，最近成功同步、失败次数红色高亮、最近错误）；任务日志 Drawer（状态列筛选、采集/新增/更新统计）；启用/停用（Popconfirm 确认，停用附原因）；手动触发采集管道（确认弹窗 + 后端返回信息反馈，实测返回「处理流水线已加入队列」）。
6. **手工录入**：ModalForm 分组表单（基本信息/来源归因/漏洞标识/影响范围/风险评估），字段与校验对齐后端契约（标题长度、CVE 格式、URL 绝对地址、来源名称与 URL 至少一项、CVSS 0-10、风险分 0-100、标签 tags 模式）；提交成功后列表刷新。共享组件 `ManualEntryCreateButton` 同时供情报列表页复用。
7. **通用**：枚举中文标签与徽章色沉淀为 `src/constants/labels.ts`（语义与旧 `labels.js` 一致）；`src/utils/download.ts` 统一导出下载；加载/错误/空状态全中文；`src/services/` 契约层结构未动（仅修正 manualEntries 列表参数 typings 与后端实际一致：GET /manual-entries 无分页返回全量数组）。

# Task 4.2 - Fixed Risk Scoring Service

## Summary
Implemented a worker-side fixed-rule scoring package for normalized threat intelligence, including a Celery entry point, deterministic explanation payloads, tests, and documentation.

## Details
Added a pure scoring rule engine that combines CVSS or severity fallback, known exploited/CISA KEV signals, public PoC signals, remote exploitability, authentication requirements, vehicle-critical component impact, multi-vendor/common component impact, and source confidence. Added a scoring service that selects normalized rows needing a first score or still carrying the default `info` level, supports `force=True` re-evaluation, and updates rows idempotently without creating records or changing unrelated normalized fields.

The scorer stores bounded 0-100 `risk_score`, mapped `risk_level`, and deterministic explanation data under `metadata.scoring`. No schema or migration changes were required because the existing worker and backend table shape already includes score, level, and metadata fields.

# Task 2.1 - Database Models and Migrations

## Summary
Implemented the backend persistence foundation with SQLAlchemy models, Alembic migration wiring, an initial PostgreSQL migration, admin bootstrap password hashing, focused tests, and documentation updates.

## Details
Worked in `/home/myx/SentinelDrive/.apm/worktrees/feat-database-models` on branch `feat/database-models`. Added SQLAlchemy 2.x and Alembic as the ORM/migration stack, preserving the existing `DATABASE_URL` contract. Modeled users, sources, sync state, job logs, raw intelligence, normalized threat intelligence, source attribution links, alerts, audit events, and export jobs.

The schema includes deterministic deduplication constraints for raw hashes, source external IDs, normalized dedup keys, and intelligence source URLs. It includes PostgreSQL JSONB fields, array tags/source fields, vehicle component and attack surface enums, GIN indexes for tags and full-text search vectors, and indexes for CVE/CWE, risk/status, timestamps, vendor/product, components, alerts, audit events, and exports.

Raw intelligence supports metadata-only retention for HTML/PDF sources through URL, title, summary/snippet, hashes, fetch metadata, parsing/processing status, and nullable `raw_content`. Admin bootstrap now reads configured environment values and stores only a bcrypt password hash.

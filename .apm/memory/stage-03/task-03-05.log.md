# Task 3.5 - Normalization and Deduplication Pipeline

## Summary
Implemented a worker-side normalization pipeline that converts raw intelligence rows into shared threat intelligence records with deterministic deduplication and source attribution.

## Details
Added a normalization package with a registry, data models, dedup helpers, vehicle/attack-surface hints, source-specific normalizers, and a database-backed service. The service reads pending or collected raw rows, dispatches to the correct normalizer, upserts `threat_intelligence`, upserts `threat_intelligence_sources`, and updates raw row parsing/processing status independently per row.

Implemented normalizers for NVD, CISA KEV, RSS, vendor advisories, manual raw rows, and fallback API rows. CVE IDs are preferred for deduplication across sources, followed by canonical URL, title/source, and content/text hashes. Merge behavior preserves source names and URLs, updates source attribution `last_seen_at`, and fills structured fields conservatively without replacing stronger structured values with weaker fallbacks.

Added the stable Celery task entry point `sentineldrive.normalize_raw_intelligence` while keeping it separate from source collection. Updated worker table mirrors for normalized intelligence and source attribution without adding migrations.

Committed changes on branch `feat/normalization-deduplication` with commit `1f67c00` using message `feat: add normalization pipeline`.

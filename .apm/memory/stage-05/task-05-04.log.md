# Task 5.4 - Manual Entry and User Basics UI

## Summary
Built manual intelligence entry and basic user management screens using the shared authenticated data layer. Committed the work at `f9c2ff7`.

## Details
Replaced the manual-entry placeholder with a form and list workflow using `manualEntriesApi.list`, `manualEntriesApi.create`, and `manualEntriesApi.update`. The form supports required and optional backend fields including category, title, summary, source name/URL, CVE/CWE, CVSS, severity, vendor/product/version, vehicle component, attack surface, exploit status, confidence, risk score/level, tags, and status. Added Chinese client-side validation for required fields, URL/CVE format, numeric ranges, and obvious credential-like text.

Replaced the user placeholder with current-user display and admin-only user management. Admins can list users, create users, and enable or disable users through `usersApi`; non-admins see a disabled management state. Password values remain input-only and are not displayed after submission.

Added compact record-list, checkbox, and success-message styling.

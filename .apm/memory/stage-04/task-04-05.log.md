# Task 4.5 - Export Services

## Summary
Implemented authenticated MVP export endpoints for intelligence and alert workflows on top of the source status API branch.

## Details
Added `/exports/intelligence.csv`, `/exports/intelligence/{intelligence_id}/markdown`, `/exports/alerts.csv`, and `/exports/summary.pdf`. Intelligence CSV exports reuse the existing intelligence filter and sort helpers, alert CSV exports reuse the alert filter and sort helpers, and both apply bounded limits. The Markdown endpoint exports one normalized intelligence record with safe core fields, source attribution, and related alert summaries.

The PDF endpoint returns a lightweight single-page security operations summary generated directly by the backend without adding a new dependency. Export output uses safe public fields only and avoids raw source payloads, unsafe metadata, credentials, tokens, and secret-like values.

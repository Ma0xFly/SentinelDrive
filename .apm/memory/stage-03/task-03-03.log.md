# Task 3.3 - RSS and Vendor Advisory Connectors

## Summary
Implemented configurable RSS/Atom collection and endpoint-driven vendor advisory metadata collection using the existing connector runtime and raw payload shape.

## Details
Added built-in `rss` and `vendor-advisories` Connectors. RSS supports configurable feed objects from environment or database-backed source metadata, parses RSS 2.0 and Atom with standard-library XML handling, preserves feed attribution and timestamps, and emits deterministic raw/content hashes from GUIDs or canonical URLs.

The vendor advisory Connector uses configured endpoint objects, seeds representative BYD, NIO, Li Auto, Qualcomm, and Bosch endpoints, fetches lightweight HTML metadata, records advisory-like links, and keeps HTML/PDF-derived records metadata-only without downloading PDF attachments. Endpoint failures are isolated where other endpoints can still produce records, while all-endpoint failure raises a sanitized `ConnectorError`.

Extended source configuration to accept `SOURCE_RSS_FEEDS` and `SOURCE_VENDOR_ADVISORY_ENDPOINTS` JSON lists, preserve safe database-backed feed/endpoint metadata, and exclude credentials/private headers from runtime summaries. Updated documentation and Compose environment wiring for the new settings.

Committed changes on branch `feat/source-connectors` with commit `37e51c3` using message `feat: add rss and vendor connectors`.

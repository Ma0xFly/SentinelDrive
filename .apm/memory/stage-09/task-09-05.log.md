# Task 9.5 - E2E 移植、部署切换与文档

## Summary

完成 Stage 9 收尾：旧 Next.js 前端移除、Ant Design Pro 新前端归位并切换为 nginx 静态托管部署；Playwright E2E 全量移植并新增仪表盘场景（9/9 通过）；修复两个测试缺陷；同步全部受影响文档。部署切换经 compose 重建与 reverse-proxy 验证通过，`/api/stats/overview` 带 token 返回 200 且有数据。

## Details

四个子任务按序完成：

1. **E2E 移植与新增**：在 `frontend/e2e/operator-workflows.spec.ts` 从零移植 6 个旧场景语义到新前端（登录守卫、情报列表/详情/导出、外部 ingest 记录、告警流转、数据源触发、手工录入），新增 2 个仪表盘场景（非零统计卡片+图表渲染、零值空态）。配置 `playwright.config.ts`（webServer 用 `MOCK=none` 且 `BACKEND_PROXY_TARGET=http://127.0.0.1:1` 指向不响应地址证明 mock 隔离，baseURL 按 Umi 默认 8000）。new package.json 增加 `e2e`/`e2e:install` scripts，devDep 补 `@playwright/test`。调试过程中修正了多处新前端断言差异：antd 按钮文字带空格（`登 录`、`查 询`、`确 定`）、PageContainer/Card title 非 heading 角色、ProTable fixed 列重复渲染标题、ModalForm 默认提交按钮文字为「确 定」、菜单缺少 `/intelligence` 项（改用直 URL 导航）等。
2. **部署切换**：新增多阶段 `frontend/Dockerfile`（node:22 构建静态产物 → nginx 托管，`pnpm install --offline && pnpm build`）与 `frontend/nginx.conf`（监听 3000 匹配既有 `FRONTEND_UPSTREAM=frontend:3000`，SPA 回退 `try_files`，`absolute_redirect off` 防止目录重定向泄漏内部端口）。`git rm -r` 旧前端、`git mv` 新前端归位为 `frontend/`。`docker-compose.yml` frontend 服务移除 `NODE_ENV`/`NEXT_PUBLIC_API_BASE_URL`；`.env.example` 同步清理。重建 backend 容器镜像（运行中容器缺 stats 端点）与 frontend 镜像，`docker-compose up -d` 后经 reverse-proxy（`https://localhost`）验证：首页 200、SPA 路由跟随相对重定向 200、登录成功、`/api/stats/overview` 带 token 返回 200 且 `total_intelligence:5`。
3. **测试缺陷修复**：`test_migrations.py` 路径改为基于 `__file__`；`requirements.txt` 补 `httpx==0.28.1`。backend 目录与仓库根两处均验证通过。
4. **文档同步**：更新 `README.md`、`docs/testing.md`、`docs/development.md`、`docs/deployment.md`、`docs/environment.md`、`docs/external-ingest.md`、`docs/glossary.md`、`docs/scaffold.md` 及 3 个 `docs/qa/*` 清单：命令从 npm 改 pnpm、路径从 `frontend/app` 改 `frontend/src/pages`、移除 `NEXT_PUBLIC_API_BASE_URL` 描述、补前端静态托管说明。链接校验与 `git diff --check` 全通过。

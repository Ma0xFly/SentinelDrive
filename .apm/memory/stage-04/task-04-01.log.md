# Task 4.1 - Intelligence Search and Detail APIs

## Summary
Implemented authenticated normalized intelligence search/list and detail APIs on branch `feat/intelligence-search-api`. The endpoints support the requested filters, bounded pagination, stable sorting, source attribution, safe metadata/scoring fields, and related alert references.

## Details
Added a new backend intelligence route and response schema following the existing FastAPI/auth patterns. The list endpoint builds a PostgreSQL-oriented SQLAlchemy query with full-text search support where available, structured filters for normalized fields, bounded `page`/`limit` pagination, and sorting by recent, first seen, risk score, or severity. The detail endpoint returns normalized fields, safe source attribution, scoring metadata/explanations, and alert references when `Alert` rows are present.

Sensitive response handling was added for normalized metadata, external IDs, source URLs, and source attribution values. Raw payloads are not exposed, and metadata keys or values matching auth headers, tokens, API keys, cookies, passwords, secrets, raw payload indicators, or similar private fields are removed from API responses.
